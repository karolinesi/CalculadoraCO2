# 🌱 EcoTrip Calculator – Simulador de Impacto Ambiental para Viagens

## 📖 Sobre o Projeto

O **EcoTrip Calculator** é uma aplicação desenvolvida durante o **Bootcamp CI&T - Do Prompt ao Agente**, promovido pela DIO em parceria com a CI&T.

O projeto tem como objetivo conscientizar usuários sobre o impacto ambiental de seus deslocamentos, realizando estimativas de emissão de carbono com base em diferentes características da viagem. A ferramenta permite comparar opções de transporte e incentivar escolhas mais sustentáveis.

---

## 🎯 Objetivo

Desenvolver uma solução capaz de:

* Estimar a emissão de CO₂ de uma viagem.
* Comparar diferentes meios de transporte.
* Incentivar decisões mais sustentáveis.
* Aplicar conceitos de Inteligência Artificial, Engenharia de Prompt e desenvolvimento assistido por IA.

---

## 🚀 Funcionalidades

* Cálculo estimado da emissão de carbono.
* Seleção de diferentes meios de transporte.
* Simulação de impacto ambiental com base na distância percorrida.
* Comparação entre alternativas de deslocamento.
* Exibição de sugestões para redução da pegada de carbono.

## 📊 Como Funciona

O usuário informa os dados da viagem, como:

1. Distância percorrida.
2. Meio de transporte utilizado.
3. Características do trajeto (quando aplicável).

Com base nessas informações, a aplicação utiliza fatores de emissão pré-definidos para calcular uma estimativa da quantidade de CO₂ gerada pela viagem.

---

## 🌍 Exemplo de Uso

### Entrada

```text
Distância: 300 km
Transporte: Carro
```

### Saída

```text
Emissão estimada: 57 kg de CO₂
Impacto: Moderado
Sugestão: Considere alternativas coletivas para reduzir sua pegada de carbono.
```
